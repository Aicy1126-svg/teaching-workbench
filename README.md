# 教培备考工作台 - 产品说明

## 一、产品定位

面向【初高中教培老师 + 证书备考】的二合一轻量化效率工作台。所有数据浏览器本地保存，无需注册登录，一套代码自适应电脑端、平板端、手机端。

---

## 二、完整功能清单（15个模块）

### 📊 总览区

| 模块 | 功能说明 |
|------|---------|
| **首页总览** | 综合数据卡片：本周上课数、本月课消、本周备考时长、今日待办数；考试倒计时；课时不足预警；快捷操作入口 |
| **每日任务** | 分【教学任务】【备考任务】两区；支持打勾完成/删除/顺延；每日循环任务；集成番茄钟（区分备课计时/备考学习计时），完成后自动记录学习时长 |
| **日历看板** | 月视图日历，同时展示上课排课和备考计划；支持点击日期添加事件；三种事件颜色区分（教学/备考/重要） |
| **考试倒计时** | 添加证书考试/普通考试，自动计算剩余天数；30天内红色预警，60天内黄色提醒 |

### 📚 教学管理区

| 模块 | 功能说明 |
|------|---------|
| **排课管理** | 双视图：①教师视图（周课表，标记学生/时段/状态，支持编辑）②学生视图（选学生生成专属排课清单，一键复制文本发家长）|
| **备课文档库** | 每节课双版本文档：教师版备课稿（完整思路/话术/拓展，仅自己可见）+ 学生版讲义（可复制文本发学生）；按学生名/日期归档 |
| **课消台账** | 记录每位学生总课时/已上课时/剩余课时；进度条可视化；不足预警；一键复制课时记录文本发家长核对 |
| **成绩档案** | 区分校内考试/机构测试录入分数；自动生成成绩趋势折线图；按学生筛选查看 |
| **课后反馈生成器** | 输入学生姓名/授课内容/课堂状态/薄弱点/后续重点 → AI一键生成家长反馈文案；4种语气风格（专业/温和/简明/详细）；支持保存常用模板 |
| **中考分数测算器** | 内置泉州德化中考折算比例（语文×1.0/数学×1.0/英语×1.0/物理×0.9/化学×0.6/历史×0.5/道法×0.5/体育×1.0/实验×1.0/地理×0.3/生物×0.3）；输入原始分自动折算投档总分；录入目标高中AI生成提分计划；分数线手动录入 |

### 📁 备考 & 素材区

| 模块 | 功能说明 |
|------|---------|
| **素材库** | 卡片式素材管理；支持文字+图片粘贴；预设标签（初中教学/易错题/家长话术/考证真题/背诵笔记）+标签筛选；支持百度网盘文件导入（下载到本地后上传）|
| **真题集** | 导入真题图片；标记错题；自动生成错题复盘清单；统计真题/错题数量 |
| **错题收集板** | 分区存储【学生错题】【个人备考错题】；上传题目截图；记录错因解析+正确答案；支持标签检索 |
| **学习时长统计** | 统计每周备课时长/备考学习时长；最近4周柱状图；番茄钟完成自动记录；支持手动添加记录 |

### 🤖 AI 助手

| 模块 | 功能说明 |
|------|---------|
| **AI对话助手** | 内置两套角色：①理科助教（写课后反馈/备课出题/解析知识点）②备考助手（梳理考点/解析习题/制定复习计划）；对话记录保存在工作台内；右侧悬浮面板随时唤起（手机端底部弹窗）|

- 触摸友好，禁止文字选中干扰

## 六、手机/平板作为 App 使用（PWA）

工作台已升级为 **PWA（渐进式 Web 应用）**，添加到主屏幕后可像原生 App 一样全屏运行，无浏览器地址栏、无底部导航条，支持离线打开。

### iPhone / iPad 添加步骤

1. 用 Safari 打开工作台地址（局域网电脑 IP + `:8080`）
2. 点击底部工具栏的 **分享按钮**（方框+向上箭头）
3. 向上滑动，选择 **「添加到主屏幕」**
4. 点击右上角 **「添加」**
5. 返回桌面，点击新图标即可像 App 一样全屏打开

### Android / 电脑 Chrome 添加步骤

1. 用 Chrome / Edge 打开工作台
2. 点击浏览器右上角菜单（⋮）→ **「安装应用」** 或 **「添加到主屏幕」**
3. 按提示完成安装

### PWA 特性说明

| 特性 | 说明 |
|------|------|
| 全屏运行 | 隐藏浏览器地址栏和底部工具栏 |
| 独立图标 | 主屏幕显示应用图标和名称 |
| 启动画面 | 从主屏幕打开时显示 App 风格启动画面 |
| 离线可用 | Service Worker 缓存核心文件，断网也能打开 |
| iOS 安全区适配 | 自动适配刘海屏、底部手势条 |

### 局域网访问说明

如果要在手机/平板使用，需保证设备与电脑连接**同一个 WiFi**，然后用电脑的局域网 IP 访问，例如：

```
http://192.168.1.100:8080
```

电脑 IP 可在命令提示符中输入 `ipconfig` 查看。

## 七、自定义修改指南

### 1. 新增功能模块

在 `js/app.js` 中按以下步骤操作：

**步骤1：在 MODULE_NAMES 中注册名称**
```javascript
const MODULE_NAMES = {
  // ... 已有模块
  myModule: '我的模块',  // 新增
};
```

**步骤2：在 HTML 侧边栏添加导航项**
```html
<a class="nav-item" data-module="myModule">
  <span class="nav-icon">🔧</span>
  <span class="nav-label">我的模块</span>
</a>
```

**步骤3：在 Modules 对象中添加模块渲染函数**
```javascript
Modules.myModule = function() {
  return `
    <div class="module-header">
      <div class="module-title">我的模块</div>
    </div>
    <div class="card">
      <!-- 你的内容 -->
    </div>
  `;
};
Modules.myModule.bindEvents = function() {
  // 绑定事件
};
Modules.myModule.init = function() {
  // 初始化逻辑
};
```

### 2. 修改配色方案

在 `css/style.css` 顶部的 `:root` 中修改 CSS 变量：
```css
:root {
  --color-primary: #8B9A8B;   /* 主色调：修改这里 */
  --color-secondary: #C4B59C; /* 辅助色 */
  --color-accent: #B5A0B0;    /* 强调色 */
  --bg-main: #F5F3F0;         /* 背景色 */
  /* ... */
}
```

### 3. 修改中考分数折算比例

在 `js/app.js` 的 `Modules.scoreCalc` 函数中修改 `subjects` 数组的 `ratio` 值：
```javascript
{ key: 'physics', name: '物理', full: 100, ratio: 0.9 },  // 修改 ratio
```

### 4. 修改番茄钟时长

在 `js/data.js` 的 `Models.settings` 中：
```javascript
settings: {
  pomodoroWorkMin: 25,  // 工作时长（分钟）
  pomodoroBreakMin: 5,  // 休息时长
}
```

### 5. 新增/隐藏/重命名板块

- **新增**：参考第1点
- **隐藏**：在 HTML 中删除或隐藏对应 `.nav-item`
- **重命名**：修改 `MODULE_NAMES` 和 HTML 中 `.nav-label` 的文本

### 6. 数据备份与恢复

- 左侧栏底部「导出数据」→ 下载 JSON 备份文件
- 「导入数据」→ 选择备份文件恢复

### 7. 修改 PWA 应用信息（图标/名称/主题色）

**修改名称/主题色/描述**：编辑 `manifest.json`
```json
{
  "name": "教培备考工作台",
  "short_name": "教培工作台",
  "theme_color": "#8B9A8B",
  "background_color": "#F5F3F0"
}
```

**修改图标**：运行 `generate_icons.py` 可重新生成 `icons/icon-192.png` 和 `icons/icon-512.png`。

**修改 iOS 状态栏/主题色**：编辑 `css/style.css` 中 `:root` 的 CSS 变量和 `@media all and (display-mode: standalone)` 相关样式。

## 八、技术架构

```
teaching-workbench/
├── index.html          # 主页面结构
├── manifest.json       # PWA 应用清单
├── sw.js               # Service Worker（离线缓存）
├── generate_icons.py   # App 图标生成脚本
├── icons/
│   ├── icon-192.png    # 主屏幕图标（iOS/Android）
│   └── icon-512.png    # 大图标/PWA 商店图
├── css/
│   └── style.css       # 莫兰迪主题 + 响应式样式
└── js/
    ├── data.js         # localStorage 数据层 + 工具函数
    └── app.js          # 主控制器 + 15个功能模块 + PWA 注册
```

- **零依赖**：纯 HTML/CSS/JS，无需安装任何框架
- **本地存储**：所有数据通过 localStorage 保存
- **Canvas图表**：成绩趋势折线图、学习时长柱状图（原生Canvas，无外部库）
- **PWA 支持**：manifest + Service Worker，可添加到主屏幕、离线使用
