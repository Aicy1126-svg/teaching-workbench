# 教培备考工作台 · 账号云同步

一体化服务器：**网页 + 同步 API 同源**，登录只需「用户名 + 密码」，无需填写任何服务器地址。

## 在本机（电脑）启动

双击项目根目录的 **`启动工作台.bat`** 即可（会自动启动服务器）。
或手动：

```bash
cd sync-server
node server.js
```

启动后浏览器打开 **http://localhost:8080** 就能用。

## 账号登录（极简）

1. 点右上角 **「☁️ 登录同步」**
2. 输入**用户名 + 任意密码**（首次输入会自动注册账号；用户名不要和别人重复即可，密码随便设、自己记住）
3. 之后用同一账号在任意设备登录，数据自动同步

就这么三步，没有服务器地址、没有 IP、没有配置、没有格式限制。

## 在手机 / 平板上同步

手机、平板与电脑连**同一个 WiFi**，在浏览器打开电脑上显示的网址
（登录后点账号 → 同步菜单里会显示，例如 `http://192.168.1.100:8080`），
用**同一个账号**登录即可同步全部数据。

> 所有数据默认存在本机浏览器；登录后写入云端，换设备登录自动拉取。

## 部署到公网（可选，脱离同一 WiFi）

如需在任何网络下同步，把 `sync-server/` 部署到任意支持 Node.js 的平台
（Railway / Render / 自己的服务器），拿到一个公网域名后：
- 电脑、手机都打开该域名网址
- 用同一账号登录即可

部署配置已备好：`railway.json`、`render.yaml`。

## 数据说明

- 账号与同步数据存于 `sync-server/data/`（JSON 文件）
- 备课文档（PDF/Word）与手写备课图存于浏览器 **IndexedDB（本机）**，不随账号上传
- 排课、学生、便利贴等文本数据随账号云同步
