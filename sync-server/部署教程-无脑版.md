# 教培工作台 · 部署到公网（无脑步骤版）

目标：拿到一个**永久不变**的公网地址，手机/平板在任何网络下都能同步。
不需要 Cloudflare。用 **Railway**（免费、最简单）。

---

## 第 1 步：注册 GitHub（1 分钟）

1. 打开 https://github.com
2. 点右上角 **Sign up**（用邮箱注册，免费）
3. 收邮件验证 → 完成注册

> 记好你的 **GitHub 用户名** 和 **密码**（第 4 步要用）。

---

## 第 2 步：生成"访问令牌"（30 秒，用于让脚本替你上传代码）

> 原因：GitHub 不支持用密码上传代码，需要专门的一个"钥匙"（token）。

1. 登录 GitHub 后，打开这个链接（直接复制粘贴到浏览器）：
   https://github.com/settings/tokens/new
2. 页面里：
   - **Note** 填：`teaching-workbench`（随便写）
   - 勾选 **repo**（全部勾上 repo 那一项即可）
   - 拉到底点 **Generate token**（绿色按钮）
3. 生成后会出现一串 `github_pat_xxx...` 的字符——**立刻复制保存**（只显示这一次！）
   - 粘贴到记事本备用，后面要用。

---

## 第 3 步：在 GitHub 建一个空仓库（30 秒）

1. 打开 https://github.com/new
2. **Repository name** 填：`teaching-workbench-sync`（随便起，英文）
3. 其他**全部默认**（不要勾 README、不要勾 .gitignore）
4. 点 **Create repository**

建好后，页面地址栏类似：
`https://github.com/你的用户名/teaching-workbench-sync`
→ 复制这个**仓库地址**备用。

---

## 第 4 步：双击一键上传脚本（你只需填两处）

回到电脑上这个项目文件夹，双击 **`部署上传.bat`**，它会让你输入：
1. 你的 GitHub 用户名
2. 第 2 步生成的令牌（token）
3. 你的仓库名（如 `teaching-workbench-sync`）

输完回车，脚本自动把代码推到 GitHub。

> 如果提示登录，把第 2 步的 token 当密码填即可。

---

## 第 5 步：在 Railway 一键部署（2 分钟）

1. 打开 https://railway.app
2. 点 **Login** → 选 **GitHub** → 授权登录
3. 登录后点 **New Project** → **Deploy from GitHub repo**
4. 选中第 3 步建的仓库 `teaching-workbench-sync`
5. 等 1~2 分钟，部署完成
6. 点顶部的项目 → 左侧 **Settings** → **Domains**
   → 会看到一个固定地址，形如：
   **`teaching-workbench-sync.up.railway.app`**
   → 这就是你的**永久公网地址**！

---

## 第 6 步：手机/平板用起来

1. 手机浏览器打开第 5 步的固定地址（如 `xxx.up.railway.app`）
2. 右上角「☁️ 登录同步」→ 填**和电脑同一个账号**
3. 自动同步 ✅ 任何网络都能用，地址永久不变

### 让电脑端也切到固定地址（可选）
把固定地址写进 `sync-server/fixed_url.txt`（一行），下次双击 `启动工作台.bat` 就直接用固定地址，不再走临时穿透。

---

## 常见问题

**Q：token 忘了保存怎么办？**
回到 https://github.com/settings/tokens 删掉旧的、重新生成一个。

**Q：Railway 收费吗？**
免费额度够个人用；超了会暂停，不会自动扣费。需要常驻可升级（约 $5/月）。

**Q：想换成自己的域名？**
Railway/Render 的 Domains 设置里绑定即可（需你有域名）。

**Q：本地数据怎么迁到云？**
云上是独立账号体系。第一次在云地址注册同名师账号即可；要带旧数据，把本机 `sync-server/data/` 拷到云实例同目录（高级用法，一般不用）。
